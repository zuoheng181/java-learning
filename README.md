## Git 常用命令小抄

| 想做什么 | 命令 |
| --- | --- |
| 看看现在改了哪些文件 | `git status` |
| 把改动放进"待提交"清单 | `git add .` |
| 提交（存一个存档点） | `git commit -m "这次改了什么"` |
| 推送到 GitHub | `git push` |
| 把 GitHub 上的更新拉下来 | `git pull` |
| 看看提交历史 | `git log --oneline` |

> `git add .` 里的那个点，表示"当前文件夹下的所有改动"。
>
> 日常三连：`git add .` → `git commit -m "说明"` → `git push`
